# Changelog

## 0.1.0 — initial engineering foundation

- Added SwiftUI Home, Apps, JIT, Refresh, and Settings tabs.
- Added IPA file import, archive inspection, private storage, share, and removal.
- Added structural pairing-record validation, Keychain storage, original-byte export, and optional X.509 expiry extraction.
- Added network path and tunnel-interface diagnostics, TCP endpoint probe, and JSON diagnostic export.
- Added XcodeGen project configuration and GitHub Actions build, test, dependency, compatibility, and signed-release workflows.
- Clearly gated signing, app installation, refresh, and JIT activation because the signed-device bridge is not integrated.
